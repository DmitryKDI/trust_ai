# RTK в среде trust_ai

В облачной среде установлен RTK 1.1.0 в `/workspace/bin/rtk`.
Перед использованием выполните `source /workspace/onboarding/env.sh`:
это добавляет бинарник в PATH и настраивает доступные каталоги статистики.
Проверки: `rtk --version`, `rtk gain`, `rtk git status` из `/workspace/trust_ai`.

`rtk init --codex` создал локальный `.codex/hooks.json`. Наличие hook не
подтверждает автоматическую подмену: в проверенных облачных вызовах обычный
`git status` не увеличивал статистику RTK. При необходимости вызывайте RTK
явно. Не описывайте обычный вывод команды как сжатый без фактической проверки.
Если вывод RTK непригоден для диагностики, используйте `rtk bypass <команда>`.

На других компьютерах инструмент может отсутствовать. Не требуйте установки
RTK для сборки, тестирования или работы самого планировщика.
