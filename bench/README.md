# Стенд распознавания планов

Набор планов для честной оценки быстрого режима (сканы, фото, картинки).
Только примеры из открытых источников — **без клиентских данных**.

## Как добавить план

1. Папка `bench/plans/<короткое-имя>/`.
2. Картинка `plan.jpg` или `plan.png`.
3. `truth.json` — эталон, заполняется по подписям на плане:

```json
{
  "source": "откуда взят план",
  "style": "как нарисованы стены и двери",
  "inputAreaM2": null,
  "rooms": [17.1, 10.1],
  "roomsComplete": false,
  "doors": null,
  "windows": null,
  "entrance": true
}
```

- `inputAreaM2` — общая площадь, если менеджер её вводит (иначе `null`: масштаб угадывается).
- `rooms` — площади помещений в м²; `roomsComplete: false`, если перечислены не все.
- `doors`, `windows`, `entrance` — `null`, если не уверены.

## Запуск

```
cd app
npm run bench                 # отчёт в bench/report.md
BENCH_UPDATE=1 npm run bench  # зафиксировать новый базовый балл
```

Тест падает, если общий балл ниже `bench/baseline.json`. Правка распознавания принимается,
только если балл не падает; улучшение одного плана ценой других видно сразу.
