# Стенд распознавания планов

Набор планов для честной оценки быстрого режима (сканы, фото, картинки).
Только примеры из открытых источников — **без клиентских данных**.

## Как добавить план

1. Папка `bench/plans/<короткое-имя>/`.
2. Картинка `plan.jpg` или `plan.png`.
3. `truth.json` — эталон, заполняется по подписям на плане:

```json
{
  "source": "откуда взят план",
  "style": "как нарисованы стены и двери",
  "inputAreaM2": null,
  "rooms": [17.1, 10.1],
  "roomsComplete": false,
  "doors": null,
  "windows": null,
  "entrance": true
}
```

- `inputAreaM2` — общая площадь, если менеджер её вводит (иначе `null`: масштаб угадывается).
- `rooms` — площади помещений в м²; `roomsComplete: false`, если перечислены не все.
- `doors`, `windows`, `entrance` — `null`, если не уверены.

## Запуск

```
cd app
npm run bench                 # отчёт в bench/report.md (~4 мин)
BENCH_UPDATE=1 npm run bench  # зафиксировать новый baseline (только если не ниже прежнего)
```

## Правила проверки (ТЗ 7.1 п. 2)

- Основной набор — список `core` в `bench/manifest.json` (33 плана). Нет папки, картинки или
  `truth.json` у любого плана из списка — тест падает. Молчаливых пропусков нет.
- Порог — `bench/baseline.json` (`total`), сравнение без допуска: балл не ниже baseline.
- Понижать baseline нельзя: `BENCH_UPDATE=1` откажет, если новый балл ниже.
  Переменная `BENCH_ALLOW_LOWER` не отключает проверку.
- SHA-256 исходных изображений и truth зафиксированы в `bench/input-hashes.json`.
  Изменённые входы или несовпадение core с этим списком вызывают ошибку.
- Планы, которые лежат в `bench/plans/`, но не входят в `core`, оцениваются отдельным разделом
  отчёта и на порог не влияют. Перенос в `core` — по согласованию.
- В отчёте есть колонка «было» (балл плана в baseline) — сравнение до/после по каждому плану.
- «Готовых вариантов» — без ошибок проверок; «полных» — вдобавок все обязательные предметы
  размещены (к LAY-05). Готовых без полноты — завышенная оценка.

## Архивы без эталонов

`scripts/intake_plan_archive.py` сравнивает SHA-256 изображений с существующим набором
и извлекает только новые входы в отдельную папку. Он не меняет core, baseline
или эталоны. Пустые `truth.json` с пометкой unlabelled пригодны для диагностического
экспорта, но не для оценки качества. Команды и результат приёма первого архива —
[`docs/corpus-intake-2026-10-03.md`](../docs/corpus-intake-2026-10-03.md).
