## Подтверждённые ошибки и исправление

1. **Импорт проекта с обучением не был единым действием.** Транзакция проекта
   и файлов завершалась до `saveLearnedPlan`. При отказе хранилища обучения
   UI сообщал об ошибке, но новая копия проекта и файлы уже оставались в БД.
   Теперь `projects`, `files` и `learning` сохраняются одной транзакцией.
2. **Импорт нескольких примеров обучения мог сохраниться частично.** Каждый
   пример записывался отдельной транзакцией. Теперь предварительно проверенный
   пакет сохраняется одной транзакцией и полностью откатывается при ошибке.
3. **npm audit обнаружил четыре уязвимых пакета:** Electron 44.7.0, Vite 8.3.1,
   fast-uri 3.1.8, undici 6.29.0/7.30.0 (три high, один moderate).
   Обновлены Electron до 44.9.3, Vite до 8.3.5, fast-uri до 3.1.9,
   undici до 6.29.1/7.30.1. Manifest и lock-файл согласованы. Не применялись
   `audit fix --force`, отключение TLS, подмена checksum или overrides на
   несовместимую major-версию.

Регрессии сначала запускались на исходном 36a02f3: два новых теста падали,
наблюдая сохранённую часть обучения и лишнюю копию проекта после ошибки.
После исправления проверены синхронный отказ `put`, асинхронный abort,
сохранность старого проекта/файлов/примеров и защита более свежих ручных правок.

Сохранены существующие контракты: JSON проекта version 1, IndexedDB version 2,
лимиты обучения 200 страниц/5 МБ, старый импорт не заменяет новую правку,
конфликт ID создаёт отдельную копию, исходники другого проекта защищены.
Схема БД не изменялась; миграция не требуется. Геометрия, генератор,
распознавание, 2D/3D, КП и защита Electron не переписывались.

Команды выполняются из `app/` экспортированной копии; логи этого запуска
сохранены в `tmp/audit-logs/` (не включать их в Git).

  `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci --no-audit --no-fund`.
  Пропущена только необязательная для Node/browser-проверок загрузка бинарника
  Electron; проверка Windows-приложения этим не подменяется.
- `npm run typecheck`: PASS.
- `npx vitest run --exclude tests/bench.test.ts --maxWorkers=2 --testTimeout=30000`:
  160 passed, 27 skipped. Пропуски относятся к отсутствующим внешним наборам,
  не отключались в этой доработке. Новый `tests/import-atomicity.test.ts`:
  5 passed (два режима отказа для двух сценариев и защита новой правки).
- `npm run build` и `npm run desktop:build`: PASS, сборки renderer/ресурсов;
