## Воспроизведение

Из корня репозитория (Python с Pillow):

```bash
python scripts/intake_plan_archive.py /path/30_BTI_PLANS_ONLY_FIXED.zip --output /tmp/bti-intake
cd app
PLAN_DIAGNOSTIC_INPUT=/tmp/bti-intake/inputs PLAN_DIAGNOSTIC_COUNT=2 PLAN_DIAGNOSTICS=/tmp/bti-diagnostics PLAN_SOURCE_SHA=5f179401a82ae0d210c27daf05100842b3a95e66 npx vitest run tests/diagnostics.test.ts
cd ..
python scripts/render_diagnostics.py /tmp/bti-diagnostics
```

Папки новых входов именуются по хешу; соответствие исходным именам — в inventory.json.
Пустые truth.json содержат статус unlabelled и предназначены только для диагностики.
Для включения в оценку нужны проверенные площади либо другая эталонная разметка.

Проверено: инвентаризация 30/28/2, диагностика двух новых планов, typecheck,
42 unit-теста (26 намеренно пропущены). Алгоритмы и core не изменялись;
полный бенч и e2e повторно в этом приёме данных не запускались.
