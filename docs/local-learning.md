# Обучение на ручных правках

Добавлено 03.10.2026 поверх `b1f4851af6b81b7e9b5458933baa11f5ab98d2db`
в ветке `claude/festive-turing-m7na3z`. Это локальная память исправлений и
консервативный подбор назначения по примерам. Обучение нейросети и перенос
исправленных контуров на незнакомые планы в эту версию не входят.

## Как пользоваться

1. Загрузите план и постройте предварительные варианты.
2. Исправьте границы через «Быструю правку» или «Разметку». При создании
   помещения по углам/точкам выберите «Назначение новой зоны» сразу:
   ванная/совмещённый санузел, туалет, кухня, гостиная, спальня, детская,
   кухня-гостиная, прихожая, коридор, кладовая, балкон или «Не определено».
3. Проверьте назначения существующих комнат в списке «Комнаты» или свойствах
   выбранной зоны. Если автоматическое назначение верно, нажмите
   «Подтвердить назначение». Смена типа не меняет контур. После смены типа
   или границ пересоберите мебель: предыдущие варианты могут стать устаревшими.
4. Проверьте масштаб, стены и проёмы. Раскройте «Обучение на моих правках»
   и нажмите «Сохранить проверенный план для обучения».
5. При следующей загрузке тех же байтов файла и той же страницы, даже в
   другом проекте и под другим именем, программа восстановит сохранённую
   геометрию, масштаб и назначения, затем заново рассчитает мебель.

Ручные стены (тип, толщина, положение) и удалённые ложные проёмы входят
в ту же память. Инструмент «Стена» теперь доступен в быстрой правке:
[manual-walls.md](manual-walls.md). На новые файлы стены не переносятся.

Для чистого распознавания снимите «Использовать мои проверенные планы и
примеры назначений» на шаге загрузки. «Забыть эту страницу» удаляет конкретный
пример; «Очистить обучение» удаляет все примеры, сохраняя проекты.
Отмена в редакторе меняет проект, но не ранее сохранённый пример: сохраните
проверенный план повторно, чтобы обновить память.

## Как используются примеры на новом плане

Новый файл сначала обрабатывает обычный распознаватель. Для незаверенных зон
дополнительный подбор сравнивает долю площади квартиры, отношение сторон
ограничивающего прямоугольника, заполненность прямоугольника контуром и
расстояние до края общего прямоугольника зон. Масштаб и поворот на 90° не
меняют эти признаки. Изображение, надписи и легенда этим механизмом не изучаются.

Примером назначения считается только явный ручной выбор/подтверждение
`Room.typeSource = manual` с типом, отличным от `other`. Утверждение всей
геометрии не превращает автоматические названия в обучающие метки. Старые
проекты без `typeSource` требуют явного выбора или подтверждения типа.

Параметры первой версии: веса признаков `[0.35, 0.4, 0.8, 2]`, евклидово
расстояние не больше `0.16`, минимум три разных SHA-256 исходных файлов,
полное согласие типов среди близких примеров. Повторное сохранение и разные
страницы одного файла не добавляют голосов. Перекодированные копии считаются
разными файлами: это защита от повторного сохранения, а не проверка независимости
квартир. Внутренняя зона с относительным расстоянием до края больше `0.03`
не получает обученное предположение «балкон».

При конфликте или недостатке примеров дополнительный подбор не меняет
результат обычного алгоритма. Ручные и уже заверенные назначения защищены;
распознанная текстовая подпись имеет приоритет перед подбором по форме.
Контуры, проёмы и масштаб на новом файле этот этап не меняет. Результат
помечен «Предположение по вашим примерам» и требует проверки; проценты
уверенности не показываются. Похожие по форме спальня и гостиная могут быть
неразличимы. Порог расстояния — инженерное ограничение, не измеренная вероятность.

## Хранение и совместимость

Все данные остаются в браузере, отправки планов на сервер нет. IndexedDB
`trust-planner` обновлена с версии 1 до 2: добавлено хранилище `learning`,
старые `projects` и `files` не изменены. Формат проекта JSON остаётся version 1;
новые поля комнат необязательны. Экспорт проекта включает его связанные
примеры обучения, если возможно вычислить SHA-256. Полный набор переносится
отдельными кнопками «Экспорт обучения» и «Импорт обучения».

Отдельный формат: `trust-planner-learning`, version 1; запись содержит SHA-256
файла и номер страницы, время сохранения и структурированную геометрию без
изображения и ID документа проекта. Сохранённое утверждение геометрии
сбрасывается при записи примера. Ключ страницы проверяется при импорте.
Требуются положительный масштаб, простые контуры и отсутствие взаимных
перекрытий больше 100 мм² в координатах модели. Это проверка целостности,
а не доказательство совпадения с исходным чертежом.

Лимиты: до 200 страниц и суммарно 5 МБ; при заполнении удаляются старейшие
примеры. Импорт проверяет весь пакет перед записью; более старый пример не
заменяет более свежую правку. Одновременные сохранения сериализуются транзакцией.
SHA-256 требует защищённого контекста HTTPS или localhost. Если локальная
память недоступна, обычное распознавание продолжает работу с сообщением.

При замене исходного файла или выборе другой страницы PDF прежняя геометрия
сбрасывается, чтобы нельзя было обучить новую страницу на старых границах.
Повторное распознавание всё ещё является явным действием; отключение памяти
позволяет заменить текущий результат новым автоматическим результатом.

## Проверка

```bash
cd app
npm run typecheck
npx vitest run --exclude tests/bench.test.ts --maxWorkers=1
npm run bench
npm run build -- --base=/trust_ai/
npx playwright test --config=playwright.production.config.ts
npx playwright test
```

Unit-тесты проверяют обучение только на ручных метках, согласие/конфликт
примеров, отсутствие голосов от повторных страниц, неизменность контуров,
проверку импортов, миграцию старой БД и резервные копии.
Production e2e на desktop/mobile проверяет ручной тип, явное сохранение,
перезагрузку браузера, повторный файл в новом проекте, отключение памяти
и доступность выбора типа при рисовании. Бенч без пользовательской памяти
проверяет неизменность обычного распознавателя.

Точность назначения на новых реальных планах и влияние накопленных примеров
ещё не измерены. Общие причины ошибок коридора, ложного балкона и проёмов
не исправляются одним добавлением памяти. Для дальнейшего обучения границ
нужны согласованные контурные эталоны и отдельная проверка на новых планах.

Результат проверки 03.10.2026: типы/сборка проходят; unit 68 passed / 27 skipped;
обычный e2e 5 passed / 5 skipped; production e2e 4 passed. Бенч без памяти:
33 плана, `0.8792958873172777` при сохранённом пороге `0.8691096089491812`.
Проверка обучения на новых файлах пока синтетическая, не оценка точности
на размеченном независимом наборе квартир.
