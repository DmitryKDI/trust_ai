## 4. Что работает

- Кликабельный путь из 7 шагов: новый проект → план → бриф → анализ → сценарии → мини-концепция → клиентская страница; навигация боковым меню.
- Редактирование брифа (7 полей), значения переносятся на клиентскую страницу.
- Выбор сценария переносится в мини-концепцию и клиентскую страницу.
- SVG-символы мебели хорошего качества (вид сверху): диван, кресло, журнальный стол, консоль/ТВ, двуспальная и односпальная кровати с изголовьем и подушками, тумба, шкафы (верт./гор.), рабочий стол, игровой ковёр, обеденная группа. Стиль чертежа соответствует ТЗ (светлый лист, графитовые стены, сине-серые окна и мокрая зона).
- Расчёт ориентира по работам от площади из брифа (35–40 тыс. ₽/м²).
- Печать клиентской страницы через `window.print()`.

## 6. Найденные дефекты вёрстки

1. **Горизонтальная прокрутка на телефоне.** При ширине 375 px страница раздувается до 1083 px на всех шагах. Причина: `.shell{grid-template-columns:1fr}` в медиазапросе + `.nav button{white-space:nowrap}` — трек `1fr` имеет `min-width:auto` и растягивается по ширине навигации. Исправление: `minmax(0,1fr)`.
2. **Вертикальное центрирование на высоком экране.** `.main{margin:auto}` внутри грида центрирует контент по вертикали — при высоком окне над содержимым пустая полоса (видно на `docs/screenshots/4-scenarios.png`). Исправление: `margin:0 auto`.
3. Печать: стили `@media print` отсутствуют — печатается вместе с боковой панелью и кнопками.
