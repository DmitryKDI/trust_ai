# Автоматическое чтение плана

Программа сама находит стены, окна, двери, помещения, масштаб и назначение комнат — в браузере, без платных сервисов. Всё найденное — подсказка: менеджер правит назначение в списке «Комнаты» или стены в редакторе.

## Как устроено

1. **Стены:** «чернила» страницы без цветных размеров и текста → закрытие (заполняет штриховку и пару линий перегородки) → открытие (убирает тонкие линии) → вытянутые участки становятся стенами (ось и толщина).
2. **Проёмы:** разрыв между соосными кусками стены или между свободным торцом и соседней стеной. Окно — остекление или наружный разрыв без дуги; дверь — дуга открывания (PDF — по векторам, скан — по картинке).
3. **Помещения:** замкнутые области; область без дверей — полость или шахта.
4. **Масштаб:** по размерным цифрам (PDF), иначе по общей площади, которую вводит менеджер.
5. **Назначение:** по подписям («кухня», «с/у»…), иначе по признакам — вход, размер, окна, близость к санузлам.

## Качество на примерах (IoU с ручной разметкой, 1 — полностью)

| План | Режим | Масштаб | Результат |
| --- | --- | --- | --- |
| pilot-r | PDF | по размерам, точно | детская 0,94, спальня 0,97, санузлы 0,96–0,97, кухня 0,84; прихожая слита с гостиной |
| republic | PDF | по размерам, точно | кухня-гостиная 0,95, спальня 0,96; санузел частично |
| ever | PDF | по размерам, точно (в штампе ошибочно 1:50) | санузлы 0,91–0,97, гостевая 0,95; часть комнат слита |
| republic | как скан | по площади | 0,84 / 0,79 / 0,69, назначения верные |
| ever | как скан | по площади | большинство комнат 0,73–0,94 |
| pilot-r | как скан | по площади | спальня слита с прихожей |

Настоящих сканов БТИ в материалах не было — это следующая проверка.
