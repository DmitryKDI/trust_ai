## Геометрия и зонирование

Экспортированы все 33 результата: источник, SHA-256 изображения, масштаб,
контуры, проёмы, текущие назначения, площади, перекрытия. Визуальные панели:
оригинал; контуры без исходника; наложение с номерами и площадями.
Цвет панели обозначает номер зоны и не является распознанным назначением.

На 17 планах обнаружены 44 пары перекрывающихся зон с площадью пересечения
больше 0,0001 м². Это структурная диагностика модели, а не сравнение с эталоном.
Числовые площади зависят от масштаба алгоритма; на некалиброванном плане
они не являются независимым измерением. Итоги по каждому примеру сохранены в
`bench/diagnostics/baseline-summary.json`, среда — в `baseline-metadata.json`.

`net15`: семь зон, восемь дверных проёмов, ноль окон. Коридор пересекается
с ванной и туалетом: по 0,224296 м². Количество зон само по себе не подтверждает
правильность контура. Подписи на плане и назначения модели не согласованы.
`truth.json` содержит лишь три площади и помечен неполным; геометрических эталонов нет.

## Изменения этого этапа

- Бенч требует точный состав набора и проверяет SHA-256 изображений и truth.
  Отсутствующие файлы, изменённые эталоны вызывают ошибку. Новые планы остаются в отдельном разделе отчёта.
- Порог проверяется без допуска 0,005 и без обхода при изменении числа планов.
  `BENCH_UPDATE=1` также не позволяет понизить порог.
- Добавлен opt-in экспорт диагностики и отдельный рендерер на Pillow.
- Добавлен браузерный контроль открытого net15 на desktop и mobile:
  загрузка, worker, семь зон, калибровка по площади и сохранение источника после
  завершения автосохранения. Это проверка процесса, не доказательство геометрической точности.

## Команды проверки

```bash
cd app
npm ci --ignore-scripts
npm run typecheck
npm run build
npx vitest run --exclude tests/bench.test.ts
npm run bench
PW_CHROMIUM=/absolute/path/to/chromium npx playwright test
PLAN_DIAGNOSTICS=/absolute/path/to/review PLAN_SOURCE_SHA=<source-sha> npx vitest run tests/diagnostics.test.ts
cd ..
python scripts/render_diagnostics.py /absolute/path/to/review
```

Для рендерера нужны Pillow и DejaVu Sans; он не обращается в сеть.
Повторный экспорт очищать или писать в новую папку. Изображения генерируются
из данных контура; они не являются нейросетевой перерисовкой.
