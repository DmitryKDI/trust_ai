## 3. Итоговая рекомендация

1. **Поиск скиллов:** основной канал — официальный `/plugin` маркетплейс Claude Code; skills.sh / `find-skills` — только как поисковик, без `add -g -y`, с `DISABLE_TELEMETRY=1`.
2. **Установить (проектно):** `frontend-design` — единственная установка, которую предлагаю сейчас. Нужно ваше «да».
3. **Уже есть, ставить не нужно:** `pdf`, `skill-creator` (eval-режим — только по согласию: тратит лимит).
4. **Не ставить:** `webapp-testing`, `playwright-cli` — Playwright подключаем как dev-зависимость проекта по ТЗ.
5. Для геометрии скиллы не нужны — библиотеки + тесты Vitest.
