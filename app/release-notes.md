Усиление защиты Windows-приложения и резервных копий.

- При импорте с совпадающим ID создаётся отдельная копия: прежний проект и исходники сохраняются.
- Установленный EXE проверяет целостность архива программы и не загружает код из подставной папки app.
- Запуск через ELECTRON_RUN_AS_NODE и внедрение через NODE_OPTIONS отключены.
- Усилена проверка отправителей системных запросов, переходов и скачиваний.
- Окно приложения не выполняет сетевые запросы и не загружает внешние изображения автоматически. Для старых референсов по ссылкам загрузите файл изображения. Локальные изображения и 3D сохраняются.
- Обновления продолжают работать через отдельный канал с проверкой контрольной суммы.

Обновление: «Справка → Проверить обновления». Проекты сохраняются.
