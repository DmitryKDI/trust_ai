Проверка обновлений при запуске и через «Справка → Проверить обновления».

- Скачивание новой версии из GitHub Releases с индикатором прогресса и проверкой целостности файла.
- Установка и перезапуск по кнопке; открытый проект сохраняется перед обновлением.
- Проекты, исходные планы, материалы и настройки остаются на компьютере.
- Сохраняются правки редактора: смешанное выделение через Shift, уменьшение подписей при отдалении и замыкание комнат по Enter.

Версию с обновлениями нужно один раз установить поверх предыдущей. Следующие выпуски можно загружать из программы.
